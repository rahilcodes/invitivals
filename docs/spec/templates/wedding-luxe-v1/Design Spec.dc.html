Product design specification

Wedding Luxe — Template V1

A premium digital wedding invitation · companion to the live prototype · open the prototype →

1 · User journey & emotional arc

95% of guests arrive via a WhatsApp link on mobile. The site is a single scroll choreographed as a six-beat emotional arc:

Curiosity
Envelope intro: names fade in behind a double hairline frame; one button, one quote. Nothing else.
Surprise
“Open Invitation” dissolves the intro, ambient music begins, the hero photo Ken-Burns behind mask-revealed names.
Emotion
Couple portraits → Our Story timeline: personal, funny, specific copy. This is where guests forward the link.
Anticipation
Dark countdown interlude — the palette inverts once, making the ticking numbers feel like an event.
Practicality
Events, venue, map, hotels, dress code, menu — all answerable in under 30 seconds each, thumb-reach CTAs.
Celebration
Gallery, film, guest wishes, then the RSVP card as the climax; FAQ and contact close the loop.

2 · Information architecture

One page, 19 sections, fixed order (emotional → practical → commitment). Sticky glass nav carries only three targets: Events, Venue, RSVP — everything a returning guest needs. RSVP is deliberately near the end but always one tap away.

Intro → Hero → Couple → Our Story → Countdown → Day Timeline → Events → Family → Venue → Map → Hotels → Dress Code → Menu → Gallery → Film → Wishes → RSVP → FAQ → Contact → Footer

3 · Typography system

Cormorant Garamond & italic
Display & headings · weights 300–600 · italics reserved for emotional emphasis and the ampersand
Jost — body, labels, UI
Weights 300–500 · overline labels: 10–11px, uppercase, letter-spacing .24–.34em, gold

Scale (mobile → desktop via clamp): names 52→110px · H2 34→52px · H3 20→26px · body 14–15px/1.7–1.8 · overline 10–11px. Nothing under 10px; body copy never under 13px.

Rule: one light surface, one tinted surface, one metallic accent, one dark interlude. The dark section appears exactly twice (countdown, wishes/footer) so it stays dramatic. Roadmap palettes (Champagne, Emerald, Rose Gold, Royal Blue, Maroon…) are eight-value swaps.

5 · Design tokens

space: 4 / 8 / 12 / 16 / 24 / 34 / 52 / 96 (section padding 96px)
radius: 0 (cards) · 2–4px (media) · 999px (pills, arches, avatars)
hairline: 1px goldSoft · accent rule: 1px gold, 26–46px wide
shadow: 0 24px 50px -34px rgba(ink,.4) — soft, far, low-alpha only
glass: bg 74–82% + blur(12–16px) · touch targets ≥ 44px · content max-width 680px

6 · Component library

Fourteen reusable parts, all present in the prototype:

Section header (overline + serif H2 + gold rule) · Envelope intro · Glass nav bar · Arch portrait frame · Timeline entry (dot + rail) · Countdown digit group · Snap-scroll carousel card · Event card (date block + body) · Circle avatar · Glass overlay card · Framed menu card (double hairline) · Wish card · RSVP form (pill toggle, stepper, thank-you state) · FAQ accordion · Music toggle (equalizer bars) · Photo drop-slot.

7 · Animation & interaction specs

All scroll reveals are CSS scroll-driven (animation-timeline: view()) — zero JS on the scroll path, 60fps on mid-range Android. Every section animates differently, from a fixed vocabulary of nine keyframes:

kRise / kFade
default entrance — 34px lift, .9s ease
kMask
clip-path curtain reveal — hero names, story photo, film frame
kWide
letter-spacing settle on overlines (.6em → .3em)
kL / kR
opposing slide-ins — bride/groom, hotels, wish cards
kZoom / kKen
scale settle on media; 22s Ken Burns on hero
kFloat
petal drift, 17–26s, hero only, pointer-events none
kBreath / kBar
CTA glow pulse; music-toggle equalizer

Interactions: intro button starts WebAudio ambient score (autoplay is browser-blocked — the tap is the unlock); mute toggle suspends the AudioContext; carousels use native scroll-snap; RSVP submits to an in-place thank-you state with a “change my reply” escape hatch; share uses navigator.share with clipboard fallback. prefers-reduced-motion collapses every animation to ≤10ms.

8 · Mobile-first & desktop

Designed at 390px first: single column, full-bleed media, carousels for dense content (day timeline, gallery), all CTAs bottom-of-thumb pills ≥48px. Desktop is the same column, wider: clamp() scales type, grids go 2–4 up, carousel padding centers on a 800–920px track. No separate desktop layouts to maintain — that’s deliberate for a sellable template.

9 · What differentiates it

1. An arrival ritual (envelope + music unlock), not a landing page. 2. Fashion-editorial restraint — hairlines and whitespace where competitors use script fonts and flourishes. 3. One dramatic palette inversion instead of constant decoration. 4. Copy with personality baked in as a template voice guide. 5. Eight-variable theming = infinite colorways at near-zero cost. 6. Generated ambient score — no licensing, no 3MB audio file. 7. Scroll-driven CSS animation — smooth on cheap phones, where competitors’ JS parallax judders.

10 · Self-critique — five improvements for V2

  1. Real photography is doing zero work. The design leans on photo slots; until a demo photo set ships, buyers can’t feel the final effect. V2: curated licensed demo shoot per palette.
  2. RSVP needs a real backend. The thank-you state is theater. V2: serverless endpoint + spreadsheet sync, per-guest magic links with pre-filled names.
  3. 19 sections is heavy for some couples. V2: section toggles in an admin config so a minimal 8-section build is one flag away.
  4. Scroll-driven animation needs a fallback audit. Older Safari plays entrances time-based on load; acceptable but not choreographed. V2: IntersectionObserver polyfill path.
  5. Localization & cultural variants. English-only, Western event structure. V2: language file + multi-event schemas (mehndi/sangeet, tea ceremony, nikah) — the biggest commercial unlock.

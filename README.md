All artwork is original illustrated SVG (the faceless-couple style used by real Indian
wedding e-invites), generated by `tools/generate-art.mjs` — animated flames, lanterns,
petals and stars are embedded in the SVGs themselves. Each template is one self-contained
page in `src/pages/` with its own fonts, palette, music engine and interactions.

# Wedding Luxe V1 (`/luxe`)

A premium, mobile-first digital wedding invitation template. Guests arrive via
a WhatsApp link, are met by an envelope-style intro that unlocks ambient music
on tap, and scroll a 19-section emotional arc that ends at the RSVP.

**Buyers edit one file** (`src/wedding.config.ts`) **and drop photos into
`/public/photos`.** That's the entire customisation surface.

- 📖 [SETUP.md](SETUP.md) — the 10-minute setup guide
- 🎨 [THEMING.md](THEMING.md) — palettes (8 CSS variables each) and how to add your own

## Quick start

```bash
npm install
npm run dev       # preview at http://localhost:4321
npm run build     # static site → dist/
```

## What's inside

| | |
| --- | --- |
| Stack | Astro (static output) + vanilla CSS custom properties. No Tailwind, no runtime framework. |
| JS budget | ~6.6 KB bundled (2.6 KB gzip) — one dependency-free script for music, countdown, RSVP, wishes, share, and the film lightbox. |
| Animation | CSS scroll-driven (`animation-timeline: view()`) with an automatic IntersectionObserver fallback; a fixed vocabulary of keyframes (kRise, kMask, kWide, kL/kR, kZoom, kKen, kFloat, kBreath, kBar). `prefers-reduced-motion` collapses everything to ≤10 ms. |
| Music | Generative WebAudio ambient score (no licensing, no audio file) or your own looping MP3 — unlocked by the "Open Invitation" tap. |
| RSVP & guestbook | Optimistic in-place thank-you state; optional POST to Google Sheets (Apps Script) or any webhook. |
| Sections | Envelope intro · Hero · Couple · Story · Countdown · Day timeline · Events · Family · Venue · Map (real Google embed) · Hotels · Dress code · Menu · Gallery · Film · Wishes · RSVP · FAQ · Contact · Footer — each toggleable in the config. |
| Fonts | Cormorant Garamond + Jost, self-hosted, `font-display: swap`. |
| SEO / share | Full meta + OG tags, JSON-LD Event, monogram favicon generated from the config, share image from `/photos/og.jpg` or the hero photo. |
| Accessibility | Semantic landmarks, keyboard-operable accordion/carousels/forms/lightbox, visible focus states, WCAG AA in all three palettes. |

### Interactive touches

- **Personalized links** — `?to=Guest+Name` addresses the envelope to each guest and pre-fills their RSVP (see SETUP.md).
- **Envelope doors** — the intro parts like double doors along a gold seam when opened.
- **Petal burst** — a gold petal celebration when a guest accepts the RSVP.
- **Live equalizer** — the music toggle's bars follow the actual audio through a WebAudio analyser.
- **Gallery lightbox** — tap any gallery photo for a fullscreen viewer with arrows, keyboard, and swipe.

All of it respects `prefers-reduced-motion` and stays within the transform/opacity performance budget.
